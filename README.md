# Hi, I'm Karen 👋

**Technical Project Manager · Technical Delivery Lead · Magento / Adobe Commerce engineer**

I lead software delivery for enterprise and B2B e-commerce, and I still write the code. 6+ years running delivery for multi-disciplinary teams of up to eight, on top of 15+ years in software engineering.

- 🚀 Led a seven-person senior team that launched 3 rebuilt B2B webstores (Powerfleet, DCC Engage, Jonsson Workwear) in 2 years
- 🔁 Turned a custom four-step checkout built for CTM South Africa and CTM Kenya into a reusable core later sold to Mabati
- ⚡ Supported a Magento Luma to Hyvä migration that cut JavaScript payload by about 70–90%
- 🎓 Professional Scrum Master I (PSM I) · PMP in progress · BSc Honours in Business Intelligence and Data Analytics (2027)
